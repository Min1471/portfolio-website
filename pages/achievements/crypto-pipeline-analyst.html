Overview

A personal project to practise the full path from API to dashboard. A Python job calls the CoinGecko API on a schedule, cleans the results and loads them into a SQLite warehouse. A Power BI report on top shows price trends and trading-volume patterns.

  • Python
  • Pandas
  • SQLite
  • Power BI
  • REST API

How it works

Extract

A Python script calls the CoinGecko market API every 5–10 minutes.

Load

Cleaned records land in a SQLite warehouse, so analysis always runs on current data.

Report

A Power BI dashboard of price trends and trading volume, designed for non-technical readers.
